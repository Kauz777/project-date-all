🌐 Sobre o projeto

O Project Date All é um projeto desenvolvido durante meus estudos de desenvolvimento web.

A ideia é praticar a construção de páginas web utilizando tecnologias fundamentais do front-end, trabalhando principalmente com:

🧱 Estrutura HTML
🎨 Estilização com CSS
⚡ Interações com JavaScript
📱 Responsividade
🧩 Organização de arquivos
🚀 Publicação e versionamento com Git/GitHub
